# 验收

## 自动检查

已执行结果：13 项离线资源检查通过；[GitHub Actions](https://github.com/susu2020oxo/bolishijie/actions/runs/41775891873) 已执行游戏测试，运行器报告 10 项必需测试全部通过。

`python3 tools/check_resources.py` 可离线运行。它只校验资源合同，不能证明 Java 代码编译或游戏逻辑正确。

`./gradlew build` 在 Loom/Fabric 开发环境中编译并运行服务端 GameTests：

1. 主世界、下界、末地代表性地形均有玻璃变体。
2. 矿石、远古残骸、树木、菌类、水、岩浆、容器和传送门方块不转换。
3. 所有地形变体的遮光、发光和碰撞边界与原地形匹配。
4. 草地玻璃保留动物生成标签，石头玻璃不会获得草地标签。
5. 每种地形的牛、僵尸、末影人、猪灵、恶魂、史莱姆表面生成许可与原方块匹配。
6. 同一位置、相同随机种子下，真实牛生成谓词在草地替换前后结果相同。
7. 不用工具时玻璃掉落一个原版玻璃，基岩保持不可破坏且无掉落。
8. 五种工具和四件可穿戴护甲已注册，有对应耐久，可以用原版玻璃修复。
9. 结构包围盒跨区块边界时仍正确保护方块。

## 游戏内检查（尚未执行）

使用无其他模组的新世界，固定种子，例如 `20261010`，分别检查主世界、下界和末地：

- 从地表和地下观察无色玻璃、矿脉、树木，边界相邻的不同地形玻璃之间不应出现密集内部接缝。
- 检查跨区块的村庄、要塞、废弃矿井、沙漠水井、地牢、下界要塞、堡垒遗迹、末地城和末地黑曜石柱。建筑组件和水井不可被切成玻璃。
- 主世界河流、海洋、岩浆湖和下界岩浆海仍为流体，鱼和其他实体不替换；检查灵魂沙碰撞高度与原版相同。
- 生存模式徒手挖地形玻璃，确认一次掉一个原版玻璃；放置后再次挖掘仍能回收。用玻璃和木棍合成九种装备，穿戴护甲，使用玻璃镐采掘铁矿/钻石矿并确认获得正确掉落。
- 用玻璃锄耕玻璃草地，用玻璃锹修路，确认耐久消耗与交互音效。
- 在同种子、同生物群系、同高度与相同时段的原版世界和模组世界，对比草地被动动物、地下黑暗处怪物、史莱姆区块、下界要塞怪物、末地末影人的生成。不能只看见一只怪物就认定生成规则完全一致。
- 退出重进并再次进入三个维度，地形应正常保存。旧存档已生成区块不应被修改。
