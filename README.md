## 玩法

- 主世界、下界、末地**新生成区块**中的石头、泥土、砂砾、冰、下界岩、灵魂沙、末地石等自然地形成为无色透明玻璃。
- 保留树干、树叶、下界巨型菌类、矿石、远古残骸、自然建筑、传送门、水、岩浆和实体。普通植物、装饰性小方块和积雪层也保留，避免把无碰撞植物变成阻挡生物的玻璃立方体。
- 自然建筑按结构组件的包围盒保护，包含组件范围内的原地形；地牢、沙漠水井、末地黑曜石柱也单独保护。
- 徒手挖掘地形玻璃掉落 **1 个原版玻璃 `minecraft:glass`**，它就是本模组的“玻璃碎片”，不另外注册碎片物品。不受精准采集和时运影响。重新放置的原版玻璃也可以挖回。
- 基岩外观变成玻璃，仍然不可破坏、没有掉落，保留世界边界。
- 玻璃碎片按原版配方形状制作五种工具和四件护甲，也可在铁砧上修复它们。

| 装备 | 合成材料 | 属性 |
| --- | --- | --- |
| 玻璃镐、剑、斧、锹、锄 | 原版形状，以玻璃代替矿物材料，柄仍使用木棍 | 工具耐久 96，铁级采掘能力，采掘速度 6 |
| 玻璃头盔、胸甲、护腿、靴子 | 原版护甲形状，以玻璃作材料 | 护甲值依次为 2、6、5、2，耐久系数 8 |

例如玻璃镐：

```text
玻璃  玻璃  玻璃
      木棍
      木棍
```

玻璃剑是竖直排列的「玻璃、玻璃、木棍」。获取玻璃后，九种配方自动加入配方书。装备有独立的浅蓝色透明风格纹理和中英文名称。

## 生物生成

地形玻璃不是直接把所有地面换成原版玻璃。每种地形有自己的玻璃变体，保留原地面的：

- 遮光值和发光值，防止透明外观把地下变成有天光的空间；
- 碰撞形状和是否允许该类生物在表面生成；
- 方块标签与原方块身份判定，例如草方块的被动动物生成条件。

生物群系、刷怪上限、生成高度、明暗条件和空间检查仍由原版执行，**没有强制允许所有生物在玻璃上生成**。玻璃草地可以被锄成普通耕地；锹也能按原地形修路。

这保证了实现采用保留原版条件的方式；全维度实际刷怪与其他模组的兼容性仍需在游戏中验收，不能仅凭资源测试宣称完全一致。视觉透明与遮光有意分开，因此玻璃外观透明但不会为地下带来天光。

## 安装与构建

构建后的文件应为 `build/libs/bolishijie-1.0.0.jar`。**源码 ZIP、`-sources.jar` 和 `-dev.jar` 不能作为成品模组放入 mods。**

1. 安装 Minecraft Java 1.21.10 和 Fabric Loader 0.17.3 或更高版本。
2. 将本模组的成品 JAR 与适用于 **1.21.10** 的 Fabric API 放入 `mods` 文件夹。多人游戏的服务端也需安装两者。
3. 创建新世界。旧世界已经生成的区块不会转换；尚未生成的区块会应用玻璃地形。

在有正常网络连接的电脑上，用 Java 21 构建：

```sh
./gradlew build
```

Windows 使用 `gradlew.bat build`。构建包含服务端 GameTests；测试运行配置将自动接受 Minecraft EULA，见 https://aka.ms/MinecraftEULA 。

开发启动：

```sh
./gradlew runClient
```

项目已提交到 GitHub。`Build and publish Fabric 1.21.10 mod` 工作流在 `main` 更新时编译、运行测试，并自动发布到 `downloads` 分支。公开直链无需登录或查找 Actions 附件。
